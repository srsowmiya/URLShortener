URL Shortener

A backend-based URL shortener application built using Node.js, Express.js, and MongoDB that converts long URLs into short, shareable links.

FEATURES

Generate short URLs for long links

Redirect short URLs to original websites

Store URLs securely in MongoDB

Unique short code generation

Simple and fast redirection

PURPOSE OF THIS PROJECT

This project was developed to:

Understand backend development using Node.js

Learn Express routing and middleware

Practice MongoDB database operations

Strengthen REST API concepts
